# BOT [GTA5RP] — Apple-style UI

Сборка **BOT [GTA5RP]** от TomSunrise325: редизайн интерфейса по Apple Human Interface Guidelines (скилл [apple-design-skill](https://github.com/dickwu/apple-design-skill)), лаунчер «всё в одном .exe» и патч совместимости процессора.

## Что внутри

| Путь | Что это |
| --- | --- |
| `bot/templates/*.html` | Новые шаблоны страниц (сайдбар, главная, модули, бинды, настройки) |
| `bot/static/style.css` | Дизайн: светлая и тёмная темы, Liquid Glass только на функциональном слое, режимы «уменьшить прозрачность / движение», «повышенный контраст» |
| `bot/static/js/app.js` | Логика интерфейса: иконки вместо эмодзи, состояние сайдбара, доступность |
| `tools/Launcher.cs`, `tools/app.manifest` | Лаунчер: один .exe, распаковывается в `%LOCALAPPDATA%\BotGTA5RP`, журнал `launcher.log` |
| `tools/build_exe.py` | Сборка единого .exe (накладывает UI на распакованный бот) |
| `tools/patch_main.py` | Патч `main.exe`: заменяет AMD-only инструкции (TBM/XOP) на обычные, чтобы бот запускался на Intel и Ryzen |
| `tools/scan_xop.py` | Поиск таких инструкций в `main.exe` |
| `tools/verify_patch.py` | Проверка патча: каждая заменённая инструкция сравнивается с оригиналом на случайных данных |
| `tools/AutoE.cs` | Авто-E: порт (нажимает **E**, когда зелёная зона доходит до красной линии) и стройка (жмёт показанную букву). Включение — **F5**, статус в трее |
| `tools/KeyGlyph.cs` | Распознавание буквы (F, H, G, E, Y) в квадрате под полоской мини-игры на стройке |
| `tools/Walker.cs` | Автохождение: ищет красный маркер на экране, поворачивает камеру мышью и бежит к нему (F6) |
| `tools/preview.py` | Локальный превью интерфейса на Flask с тестовыми данными |

## Как применить интерфейс

1. Возьмите оригинальную папку `bot/` (из Bot.zip).
2. Скопируйте `bot/templates` и `bot/static` из этого репозитория поверх неё.
3. Если бот падает при старте с кодом `0xC000001D` — запустите патчер:

```
pip install pefile capstone
python tools/patch_main.py bot/main.exe bot/main.patched.exe
```

и замените `main.exe` на пропатченный.

## Единый .exe

Готовый файл — во вкладке **Releases**. Первый запуск распаковывает бота (несколько секунд), дальше старт мгновенный. Нужны права администратора (их требует сам `main.exe`).

Сборка самому: положите распакованный бот в `stage/`, затем `python tools/build_exe.py .` (нужен .NET Framework 4, `csc.exe` есть в Windows).

## Авто-E (F5): порт и стройка

Пока запущен лаунчер, в трее живёт значок. **F5** включает и выключает Авто-E.

- **Порт.** Красная линия на полоске стоит на месте, зелёная зона ездит. Приложение находит центр зоны и нажимает **E**, когда он совпадает с линией; после нажатия пауза 0,6 с.
- **Стройка.** Если под полоской показана буква **F, H, G, E или Y** (красной линии нет), приложение узнаёт её и очень быстро жмёт, пока она на экране: через SendInput (Windows пропускает примерно 30 нажатий в секунду) и ещё прямой отправкой нажатий в окно игры (около 1000 в секунду). Пока буква на экране, ходьба (W и Shift) отпускается, а когда она пропала, сразу возвращается.
- Координаты рассчитаны для 1920×1080 и масштабируются по высоте экрана; окно игры должно быть в фокусе. Закрытие бота закрывает и значок в трее.

## Автохождение к маркеру (F6)

Экспериментальная функция: бот ищет красный маркер задания, поворачивает камеру и бежит к нему, при застревании прыгает вбок, а пока на экране мини-игра, стоит. Работает только когда в фокусе окно «RAGE Multiplayer». Маркер, которого не видно на экране, он не найдёт, а обходить препятствия не умеет. Все решения пишутся в `launcher.log`.
