# BOT [GTA5RP] — Apple-style UI

Редизайн интерфейса бота **BOT [GTA5RP]** по Apple Human Interface Guidelines (скилл [apple-design-skill](https://github.com/dickwu/apple-design-skill)), лаунчер «всё в одном .exe» и патч совместимости процессора.

## Что внутри

| Путь | Что это |
| --- | --- |
| `bot/templates/*.html` | Новые шаблоны страниц (сайдбар, главная, модули, бинды, настройки) |
| `bot/static/style.css` | Дизайн: светлая и тёмная темы, Liquid Glass только на функциональном слое, режимы «уменьшить прозрачность / движение», «повышенный контраст» |
| `bot/static/js/app.js` | Логика интерфейса: иконки вместо эмодзи, состояние сайдбара, доступность |
| `tools/Launcher.cs`, `tools/app.manifest` | Лаунчер: один .exe, распаковывается в `%LOCALAPPDATA%\BotGTA5RP`, журнал `launcher.log` |
| `tools/AutoE.cs` | Авто-E для мини-игры порта: следит за полоской на экране и нажимает **E**, когда зелёная зона доходит до красной линии. Включение — **F5**, статус в трее |
| `tools/build_exe.py` | Сборка единого .exe (накладывает UI на распакованный бот) |
| `tools/patch_main.py` | Патч `main.exe`: заменяет AMD-only инструкции (TBM/XOP) на обычные, чтобы бот запускался на Intel и Ryzen |
| `tools/scan_xop.py` | Поиск таких инструкций в `main.exe` |
| `tools/verify_patch.py` | Проверка патча: каждая заменённая инструкция сравнивается с оригиналом на случайных данных |
| `tools/preview.py` | Локальный превью интерфейса на Flask с тестовыми данными |

## Как применить интерфейс

1. Возьмите оригинальную папку `bot/` (из Bot.zip).
2. Скопируйте `bot/templates` и `bot/static` из этого репозитория поверх неё.
3. Если бот падает при старте с кодом `0xC000001D` — запустите патчер:

```
pip install pefile capstone
python tools/patch_main.py bot/main.exe bot/main.patched.exe
```

и замените `main.exe` на пропатченный.

## Единый .exe

Готовый файл — во вкладке **Releases**. Первый запуск распаковывает бота (несколько секунд), дальше старт мгновенный. Нужны права администратора (их требует сам `main.exe`).

Сборка самому: положите распакованный бот в `stage/`, затем `python tools/build_exe.py .` (нужен .NET Framework 4, `csc.exe` есть в Windows).

## Авто-E (F5)

Пока запущен лаунчер, в трее живёт значок. **F5** включает и выключает Авто-E: приложение раз в несколько миллисекунд смотрит на полоску мини-игры (красная линия стоит на месте, зелёная зона ездит), находит центр зелёной зоны и нажимает **E**, когда он совпадает с линией; после нажатия пауза 0,6 с.

- Координаты рассчитаны для 1920×1080 и масштабируются по высоте экрана; окно игры должно быть в фокусе.
- Проверено на записях геймплея: нажатия приходятся на моменты, когда зона проходит через линию.
- Закрытие бота закрывает и значок в трее.

## Важно

- Исходный код бота и `main.exe` в репозиторий не входят и принадлежат их автору. Проект с автором не связан.
